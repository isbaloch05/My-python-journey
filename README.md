# My Python Journey 🐍

My 100 Days of Python journey — daily practice, notes, and small projects as I learn to code and build toward AI/ML.

## About

I'm a high school student learning Python from scratch, with the long-term goal of becoming an AI engineer. This repo documents my daily progress, notes, and small projects along the way.

## Day 100 — Where This Stands Now

Day 100 marks the end of the daily-practice phase. This wasn't about mastering every corner of Python — it was about building a solid foundation through consistent, hands-on practice.

**What I've learned so far:**
- Python basics: variables, loops, functions, control flow
- Data structures: lists, tuples, dictionaries, sets
- Functional-style tools: `map()`, `filter()`, `reduce()`, lambdas
- Object-Oriented Programming: classes, inheritance, encapsulation, operator overloading, classmethods
- Intermediate concepts: decorators, generators, function caching (`lru_cache`)
- File handling, error handling, modules (`os`, `time`)
- Concurrency: `asyncio`, multithreading, multiprocessing

## What's Next: Weekly Projects

Starting now, I'm moving from daily isolated exercises to **weekly projects** — complete, working applications built end-to-end with proper documentation and clean code, instead of small daily snippets.

The goal is to shift from "I know the syntax" to "I can build something real with it."

## Research & Learning Goals

Becoming an AI engineer takes more than knowing Python syntax, so alongside building projects I'm also focusing on:
- Learning NumPy and Pandas for data analysis
- Studying the math/stats foundations behind AI (linear algebra, probability, statistics)
- Moving into machine learning fundamentals
- Reading documentation and researching how things actually work under the hood, rather than only following tutorials
- Iterating on my own — breaking things, debugging, rebuilding, and understanding *why*
